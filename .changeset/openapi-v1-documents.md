`liveOpenapiRouter` imports the OpenAPI documents Executor v1 imported. A schema
reference may reach any schema in the document: a component whose name is not
URI-encoded, a property inside a component, or a schema under `paths` or another
component. An operation that answers with an event stream or another type, such
as JSON, is a tool that asks for the other type. A path may carry a fixed query,
sent before the operation's own parameters, or a fragment, which is not sent; it
does not change the tool's name. An empty field such as `operationId:` counts as
absent, a parameter in a location OpenAPI 3 does not have is not an input, and a
request body without media types sends no body.

`openapiOperationNames` lists every operation a document declares with the name
the router gives it, reading the document as the router does.
